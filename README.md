# 反直觉研究所 · 全 AI 科普视频计划

一个纯 AI 制作的科普视频账号：画面、字幕、音乐由代码直接生成，配音用 MiniMax 语音合成，真人不出镜、不出声。

- **方向**：数学 / 物理 / 天文 / 冷知识，统一用"反直觉"串起来
- **平台**：B站、抖音、小红书，**统一横屏 16:9**
- **时长**：单期 2–3 分钟，节奏紧凑，最长不超过 5 分钟
- **口号**：你的直觉，可能是错的。

## 快速上手：拿到成片之后

1. **定名字**：在三个平台搜一下「反直觉研究所」有没有重名，确定账号名。头像可以用片头的星球图标。
2. **看一遍成片**：按 [02-SOP](02-AI制作流程SOP.md) 的检查项过一遍，有问题告诉我第几秒、哪里不对。
3. **发布**：三个平台都上传同一个横屏 MP4。标题、简介、话题从对应的文案文件复制；小红书用 3:4 封面，B站和抖音用 16:9 封面。**记得勾选 AI 生成声明。**
4. **复盘**：48 小时后按 [01 文档](01-账号定位与运营策略.md) 的复盘表记录数据。
