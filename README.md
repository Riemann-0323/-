# 反直觉研究所 · 全 AI 科普视频计划

一个纯 AI 制作的科普视频账号：画面 AI 生成，配音 AI 生成，真人不出镜、不出声。

- **方向**：数学 / 物理 / 天文 / 冷知识，统一用"反直觉"串起来
- **平台**：B站（横屏）、抖音、小红书（竖屏）
- **时长**：单期 3–4 分钟，最长不超过 5 分钟
- **口号**：你的直觉，可能是错的。

## 快速上手：第一周要做的事

1. **定名字**：在三个平台搜一下「反直觉研究所」有没有重名，确定账号名、头像（可以用 AI 生成一个吉祥物）。
2. **装工具**：剪映专业版 + 即梦（或可灵）。其他工具都是可选的。
3. **做 EP01**：按 [02-SOP](02-AI制作流程SOP.md) 的步骤走一遍，第一期会比较慢，正常。
4. **存模板**：EP01 做完后，把片头、片尾、字幕样式、水印存成剪映模板，把音色等参数填进 SOP 末尾的「固定参数」表。
5. **发布**：记得勾选 AI 生成声明。48 小时后按 [01 文档](01-账号定位与运营策略.md) 的复盘表记录数据。
