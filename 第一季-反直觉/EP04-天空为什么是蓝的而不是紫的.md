**【0:00–0:07】钩子**
天空里被散射得最多的光，其实不是蓝光，而是紫光。那天空为什么不是紫色的？

**【0:07–0:20】开场**
你可能从小就知道，天是蓝的，因为蓝光被散射了。但这个答案，只说了一半。
这里是反直觉研究所，我是所长。今天我们把这个问题问到底。

**【0:20–0:32】阳光**
先从阳光说起。
太阳光看起来是白色的，其实是一大把颜色混在一起：红、橙、黄、绿、蓝、紫。它们的区别在于波长，红光的波长最长，紫光最短。

**【0:32–1:12】瑞利散射**
阳光进入大气层，会撞上无数个氮气和氧气分子。这些分子非常小，比光的波长还要小得多。
光撞上它们，就会被弹向四面八方，这叫"散射"。
关键在于，波长越短，被散射得越厉害，而且不是一点点：散射的强度，和波长的四次方成反比。
算下来，蓝光被散射的程度，大约是红光的5倍多；紫光更夸张，将近红光的10倍。
所以，当你看向太阳以外的任何方向，看到的都是被空气分子弹过来的光。这些光里，蓝光和紫光占了大头。

**【1:12–1:21】问题来了**
那问题就来了：紫光散射得比蓝光还多，天空为什么不是紫色的？（停顿）
答案有两个。

**【1:21–1:36】原因一：太阳**
第一个原因在太阳身上。
太阳发出的光里，各种颜色的分量并不一样多，紫光本来就比蓝光少。散射效率虽然高，可原料不够，到了天上，紫光并没有多到能压过蓝光。

**【1:36–2:11】原因二：眼睛**
第二个原因，在你自己身上。
人眼分辨颜色，靠的是三种视锥细胞，大致分别对红、绿、蓝最敏感。而我们对紫光，本来就不太敏感。
天空散射过来的，其实是一团混合光：紫的、蓝的最多，绿的、黄的、红的也有一些。这团光进入眼睛，三种视锥细胞被不同程度地刺激，大脑把信号一合成，给出的答案是：淡蓝色。
所以严格来说，天空的颜色，既是物理决定的，也是你的眼睛和大脑决定的。

**【2:11–2:32】夕阳**
那夕阳为什么是红的？
傍晚，太阳贴近地平线，阳光要斜着穿过厚厚的大气层，走的路程，大约是太阳在头顶时的38倍。
一路上，蓝光和紫光早就被散射得差不多了，能坚持走到你眼里的，就只剩下红光和橙光。

**【2:32–3:06】火星**
最后来个更反直觉的：在火星上，这一切几乎是反过来的。
火星的白天，天空是一种淡淡的黄褐色；而到了日落时分，太阳周围反而会泛起一圈蓝色。
因为火星的大气非常稀薄，散射的主角换成了飘在空中的细小尘埃。这些尘埃有个特点：会把蓝光更多地往前方散射，集中在太阳周围。
2015年，美国的好奇号火星车，就亲眼拍下过一场蓝色的日落。

**【3:06–3:35】结尾**
所以下次有人问你天为什么是蓝的，你可以告诉他：因为空气，因为太阳，也因为你的眼睛。
你见过最好看的晚霞是什么颜色？评论区晒一晒。
下一期是第一季的最后一期：如果全世界80多亿人同时跳一下，地球会被撞飞吗？
你的直觉，可能是错的。我们下期见。

### 图表镜头制作要点

- **S04 波长标尺**：在光谱下方加一条刻度尺，左端 700 nm（红），右端 400 nm（紫）。
- **S06 散射**：中心一个小白点，左侧一条直线光束射入，碰撞后向四周扩散出同心圆光波。
- **S07 / S08**：柱状图的高度严格按比例：红 1.0、蓝 5.9、紫 9.4（按 700 / 450 / 400 nm 计算）。
- **S11 太阳光谱**：只画示意曲线，在蓝绿段（约 450–550 nm）最高，紫色段（400 nm 附近）明显下降。右下角标"示意"。
- **S12 视锥曲线**：三条钟形曲线，分别以蓝、绿、红色填充，三条曲线的峰都不在紫色端。右下角标"示意"。
- **S15 光程示意**：画地球的一段弧和一层薄薄的大气，两条阳光：一条垂直穿过大气（短），一条贴着地平线斜穿（长），旁边标"≈38×"。

## 6. 精简版口播稿（60–90 秒，抖音测试用）

> 约 330 字，配音约 80 秒。复用镜头：S01、S07、S08、S10、S13、S15、S16、S18、S24。

天空里散射得最多的，其实是紫光。那天空为什么不是紫色的？
阳光是各种颜色混在一起的。进入大气层后，波长越短的光，越容易被空气分子散射到四面八方。蓝光的散射程度是红光的5倍多，紫光将近10倍。
那为什么不是紫色？两个原因。
第一，太阳发出的紫光本来就比蓝光少，原料不够。
第二，人眼对紫光不敏感。天空散射过来的混合光进入眼睛，大脑合成出的颜色，就是淡蓝色。
而夕阳是红的，是因为傍晚阳光要斜穿大气层，路程是太阳在头顶时的几十倍，蓝光紫光在半路就被散射光了，只剩下红光和橙光。
更反直觉的是，火星上正好反过来：白天是黄褐色，日落反而是蓝色的。
关注反直觉研究所，你的直觉，可能是错的。

先复习一下：阳光☀️进入大气层，会被空气分子散射。波长越短，散射越厉害：
🔵 蓝光：约为红光的5倍

## 10. 事实核查

| 说法 | 核查 |
|---|---|
| 散射强度与波长四次方成反比 | 瑞利散射定律，适用于远小于波长的粒子（如 N₂、O₂ 分子）✅ |
| 蓝光散射约为红光的 5 倍多 | 按 450 nm / 700 nm：(700/450)⁴ ≈ 5.9 ✅ |
| 紫光将近红光的 10 倍 | 按 400 nm / 700 nm：(700/400)⁴ ≈ 9.4 ✅ |
| 太阳光中紫光比蓝光少 | 太阳光谱在可见光范围内大致于蓝绿段最强，紫端明显下降 ✅ |
| 三种视锥细胞，对紫光不敏感 | 人眼有 S、M、L 三种视锥细胞，台词简化为"大致对蓝、绿、红最敏感"；人眼在 400 nm 附近的光谱灵敏度很低 ✅ |
| 混合光被大脑感知为淡蓝色 | 天空散射光的光谱刺激三种视锥细胞后，感知结果为偏白的淡蓝色 ✅（Big Think 等来源） |
| 日落时光程约为太阳在头顶时的 38 倍 | Kasten–Young 大气质量公式，天顶角 90° 时约 37.9 ✅ |
| 火星白天天空黄褐色，日落时太阳周围呈蓝色 | NASA 好奇号、机遇号等多次拍摄证实 ✅ |
| 火星大气稀薄 | 火星表面气压不到地球的 1% ✅ |
| 尘埃把蓝光更多地向前散射 | 火星尘埃颗粒尺寸与可见光波长相当，蓝光更容易沿接近原方向的角度散射，所以集中在太阳周围 ✅ |
| 2015 年好奇号拍到蓝色日落 | 2015 年 4 月 15 日拍摄于盖尔撞击坑，NASA 于同年 5 月发布 ✅ |

**注意**：
- 有人会说"天空是蓝色是因为反射了海洋的颜色"，这是常见误解，可以在评论区回复：海洋是蓝色部分原因是反射天空，而不是反过来。
- 视锥细胞的"红绿蓝"是简化说法，专业观众可能会指出应称 L/M/S。可以回复认同，说明是科普简化。
