## 4. 逐字稿

> 逐字稿与 `video/ep04/script.py` 一致，修改时以代码为准。

此刻，地球上一定有一个地方，一丝风都没有。这不是天气预报，是数学证明。

这里是反直觉研究所，我是所长。今天聊一个名字很可爱的定理：毛球定理。

想象一个长满毛的球，你想把每一根毛都梳得服服帖帖，既不竖起来，也不留下旋。数学家告诉你：不可能。不管怎么梳，球上至少会有一个地方，毛会竖起来，或者卷成一个旋。这就是毛球定理，1885年由庞加莱最早证明。

现在把毛换成风。地球表面每个地方的风，都有方向和大小，就像一根根毛。既然毛不可能处处梳平，风也不可能在整个地球上处处都在吹。此刻一定至少有一个点，水平风速正好是零。它往往藏在气旋的中心，或者几股风互相抵消的地方。

但如果地球是甜甜圈形状的，情况就完全不同了：甜甜圈上的毛，可以一根不落地梳平。

这也是核聚变装置托卡马克做成甜甜圈形状的原因之一：磁场要贴着表面绕圈来约束等离子体，在球面上注定会出现磁场为零的漏洞，在环面上却不会。

还有一个更离谱的定理：此刻地球上，一定有两个正好在地球两端的点，温度一模一样，气压也一模一样。它叫博苏克–乌拉姆定理。

当然，这些都假设风、温度和气压是连续变化的。真实的大气没那么理想，但已经足够接近。

所以，当你觉得风无处不在的时候，数学说：总有一个地方，正安安静静。

如果真有一颗甜甜圈形状的星球，你觉得那里的天气会是什么样？评论区脑洞一下。

下一期是第一季的最后一期：夜空为什么是黑的？这个问题，难倒了天文学家几百年。

你的直觉，可能是错的。我们下期见。

## 8. 置顶评论

> 📌 补充：毛球定理只说"至少有一个"无风点。更精确的版本（庞加莱–霍普夫定理）是：把所有零点按"旋转方式"计数，加起来一定等于 2。比如一个气旋中心算 +1，那地球上一定还有别的零点来凑数。
> 另外，人头顶的"旋"常被拿来举例，但头皮只是半个球面，头发的旋主要是生长方式决定的，并不是这个定理逼出来的。

## 9. 事实核查

| 说法 | 核查 |
|---|---|
| 毛球定理：球面上连续的切向量场至少有一个零点 | 二维球面情形由庞加莱于 1885 年证明，布劳威尔 1912 年推广到所有偶数维球面 ✅ |
| 推论：任意时刻地球上至少有一点水平风速为零 | 把风近似为球面上连续的二维切向量场即可推出；Wikipedia "Hairy ball theorem" 条目即以此为例，零点常对应气旋中心 ✅（视频中已说明连续性前提） |
| 甜甜圈上的毛可以处处梳平 | 环面欧拉示性数为 0，存在处处非零的连续切向量场（如沿大圈方向的场） ✅ |
| 托卡马克做成环形的"原因之一"是球面上必有零点 | 磁约束需要磁力线贴着闭合曲面绕行，球面上的切向场必有零点（漏洞），环面没有这个限制；实际设计还有其他物理考量，故视频措辞为"原因之一" ✅ |
| 博苏克–乌拉姆定理：任意时刻存在一对对跖点温度、气压都相同 | 定理：从球面到二维平面的连续映射必把某一对对跖点映到同一点；Borsuk 1933 年发表（据说由乌拉姆提出猜想）。把（温度, 气压）看作连续函数即可推出 ✅ |
| 画面中的 18.6 ℃ · 1013 hPa | 示意数值，画面已标注"示意数值" |
| 画面中的风场 | 示意风场（两个气旋 + 西风带），并非真实气象数据 |
