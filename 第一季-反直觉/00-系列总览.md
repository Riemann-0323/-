# 第一季《反直觉》· 系列总览

## 季主题

五个"听起来不可能"的结论，覆盖数学、天文、物理三个方向。每期都是同一个结构：**抛出反直觉结论 → 让观众先用直觉猜 → 一步步拆解 → 最后再反转一次**。

第一季的任务不是爆款，而是**测试**：哪个领域、哪种钩子、多长的时长最适合这个账号。

## 上线顺序与理由

1. **EP01 纸对折**：最适合做首发。钩子最强，画面最好做（纸、山、月球、宇宙），不需要任何前置知识。
2. **EP02 生日悖论**：第二期换成数学概率，测试"需要动脑"的内容在三个平台的表现。
3. **EP03 星星**：辟谣型选题，测试"纠正常识"这种钩子，评论区容易吵起来，互动高。
4. **EP04 天空颜色**：物理光学，生活中人人见过，测试日常物理方向。
5. **EP05 全人类跳**：脑洞型选题，最具话题性，适合放在第一季末尾收官。

建议节奏：每周二、四、六各发一期，约两周发完第一季。

## 季内统一元素

| 元素 | 内容 |
|---|---|
| 片头钩子 | 每期第一句话就是最反直觉的结论，不寒暄 |
| 固定开场 | 「这里是反直觉研究所，我是所长。」 |
| 固定结尾 | 「你的直觉，可能是错的。我们下期见。」 |
| 结尾预告 | 每期结尾用一句话预告下一期，增加追更感 |
| 封面模板 | 左上角统一小标签「反直觉 #01」，右侧一个大数字或大结论 |
| B站合集 | 建合集「反直觉 第一季」，五期依次放进去 |

## 每期文案包含什么

每个 EP 文件都有这 10 个部分，制作时从上往下用：

1. 基本信息
2. 三平台标题
3. 封面文字
4. 完整版逐字配音稿（带时间段）
5. 分镜表（含 AI 提示词）
6. 60–90 秒精简版口播稿（抖音测试用）
7. BGM 与音效
8. 三平台发布文案
9. 置顶评论
10. 事实核查与参考来源
