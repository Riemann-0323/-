# 第一季《反直觉》· 系列总览

## 季主题

五个"听起来不可能，但数学和物理都站在它那边"的结论，覆盖天文、概率、拓扑三个方向。选题刻意避开已经被刷烂的题（光年辟谣、天空颜色、三门问题之类），每一期都有一个**大多数人没刷到过的反转**。

每期结构相同：**第一句抛出反直觉结论 → 用一个生活化的类比让人"懂了" → 再反转一次 → 一句话收尾**。

第一季的任务是**测试**：哪个领域、哪种钩子、多长的时长最适合这个账号。

## 上线顺序与理由

1. **#01 星星**：首发。题目大众能听懂，但内容是"辟谣 + 反辟谣"，评论区容易聊起来；画面也最好看。
2. **#02 公交车**：换成生活概率，测试"日常小事背后的数学"在三个平台的表现。
3. **#03 太阳系的中心**：回到天文，比 #01 更硬核，测试观众对"稍微烧脑"内容的接受度。
4. **#04 没风的地方**：纯数学定理 + 生活钩子，最冷门，测试账号能不能把冷知识做出传播力。
5. **#05 夜空为什么是黑的**：季终，问题最简单、答案最宏大，最后收在"宇宙有一个开始"，适合做收官。

每期结尾都预告下一期，形成连续追更。建议节奏：每周二、四、六各发一期，约两周发完第一季。

## 季内统一元素

| 元素 | 内容 |
|---|---|
| 片头钩子 | 每期第一句就是最反直觉的结论，不寒暄 |
| 固定开场 | 「这里是反直觉研究所，我是所长。」 |
| 固定结尾 | 「你的直觉，可能是错的。我们下期见。」（季终改为「我们第二季见」） |
| 结尾预告 | 每期结尾一句话预告下一期 |
| 画面角标 | 左上角「反直觉 #0x」，画面里不放其他标识 |
| 封面模板 | 左上角「反直觉 #0x」，两行大字结论 + 一个橙色印章短语 |
| B站合集 | 建合集「反直觉 第一季」，五期依次放进去 |

## 每期文案包含什么

1. 基本信息
2. 三平台标题
3. 封面文字
4. 逐字稿（与 `video/epXX/script.py` 一致）
5. 画面设计（每个场景画什么）
6. 60–90 秒精简版口播稿（抖音测试用）
7. 三平台发布文案
8. 置顶评论
9. 事实核查与参考来源
