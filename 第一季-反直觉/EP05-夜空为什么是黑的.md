## 4. 逐字稿

> 逐字稿与 `video/ep05/script.py` 一致，修改时以代码为准。

夜空，为什么是黑的？这个像小学生问的问题，难倒了天文学家几百年。而第一个答对方向的，是一位写恐怖小说的作家。

这里是反直觉研究所，我是所长。第一季最后一期，我们来回答这个最简单、也最难的问题。

想象你站在一片无边无际的森林里。不管朝哪个方向看，视线最后都会撞上一棵树。如果宇宙无限大、永远存在，星星又均匀地撒满了空间，那你朝夜空任何方向看，视线最后都会撞上一颗星星。

你可能会说：远处的星星很暗啊。没错，距离远一倍，星星就暗到四分之一；但离你远一倍的那一层，面积大四倍，星星也多四倍。一暗一多，正好抵消，每一层贡献的光都一样多。无限多层加起来，整个夜空都应该像太阳表面一样亮。

早在1610年，开普勒就拿这一点论证：宇宙不可能是无限的。1823年，德国天文学家奥伯斯把它正式提了出来，后来人们就叫它奥伯斯佯谬。

有人猜，是星际尘埃挡住了光。但这行不通：尘埃吸收了光就会变热，最后自己也会发光。

真正说对方向的，是1848年的爱伦·坡。他在散文诗《我发现了》里提出：望远镜里那些看不到星星的方向，是因为背景太远，那里的光，至今还没能到达我们。半个世纪后，物理学家开尔文用计算证实了这个思路。

今天我们知道，答案主要有两条。第一，宇宙有年龄，大约138亿岁。光跑得再快，也只能从有限远的地方赶过来，更远的星光，还在路上。第二，星星不会永远亮着，它们会燃尽。宇宙里根本没有足够的能量，把整个天空填满星光。再加上宇宙在膨胀，远处的光被拉长、变红、变暗，夜空就更黑了。

但最反直觉的是：夜空其实并不黑。宇宙诞生后大约38万年，整个宇宙都在发光，温度大约2700摄氏度，和白炽灯的灯丝差不多。这团光一直走到今天，被宇宙膨胀拉长了一千多倍，变成了肉眼看不见的微波。它叫宇宙微波背景辐射，温度只有零下270摄氏度。如果你的眼睛能看见微波，整个夜空，都在均匀地发着微光。

所以，夜空之所以是黑的，是因为宇宙有一个开始。你每天晚上抬头看到的那片黑，就是宇宙年龄的证据。

## 9. 事实核查

| 说法 | 核查 |
|---|---|
| 无限、永恒、均匀的宇宙里，每条视线都终止在恒星表面，夜空应和恒星表面一样亮 | 奥伯斯佯谬的标准表述 ✅ |
| 距离远一倍，亮度变为 1/4；同样厚度的球壳面积变为 4 倍，星星数也变为 4 倍，每层贡献相同 | 平方反比定律与球壳面积 ∝ r² ✅ |
| 1610 年开普勒以夜空黑暗论证宇宙有限 | 开普勒《与星际信使的对话》（1610） ✅ |
| 1823 年奥伯斯提出，后称奥伯斯佯谬 | Wikipedia "Olbers' paradox"：德国天文学家奥伯斯 1823 年描述 ✅；他并非第一个提出的人，视频用"正式提出" |
| 尘埃解释行不通：吸收光后会被加热、最终自己发光 | 热平衡论证（约翰·赫歇尔等指出） ✅ |
| 1848 年爱伦·坡在《我发现了》（Eureka）中首先提出正确方向 | 原文大意：望远镜在无数方向看到的空缺，只能解释为不可见的背景太远，其光线尚未到达我们；哈里森《Darkness at Night》称其为第一个合理的解释 ✅（画面标注"大意"） |
| 开尔文 1901 年用计算证实 | Lord Kelvin 1901 年论文给出定量论证 ✅ |
| 宇宙年龄约 138 亿年 | Planck 2018：137.9 亿年 ✅ |
| 主要原因是宇宙年龄有限、恒星寿命有限（能量不足），膨胀红移是次要因素 | 哈里森的分析：在有限年龄的宇宙里，膨胀大约只把背景亮度再降低一半 ✅ |
| 宇宙诞生约 38 万年后整个宇宙发光，温度约 3000 K（约 2700 ℃），与白炽灯丝相当 | 复合时期约 38 万年，温度约 3000 K；白炽灯丝约 2700–3300 K ✅ |
